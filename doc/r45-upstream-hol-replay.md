## ARM MiniSat failure and signed-char repair

The old HOL4 tree builds MiniSat 1.14p as an external tautology helper.  On
this ARM host the initially built executable mishandles root-level units.  The
two-variable formula

```text
p cnf 2 3
1 2 0
-1 0
-2 0
```

is UNSAT, but the unmodified executable returned `SAT` with model `-1 -2`.
The input SHA-256 is
`e7b6755c091b5e0f9da1f97d1cb9ba99c69fadf8b91156df65da2492b8739d7a`
and the incorrect result SHA-256 is
`3a9529ad88b0687bfd151138ff73c65f6e4ac724c8b07ee5ef1904bc689ca271`.
As a control, the equivalent four-clause formula without unit clauses was
correctly reported UNSAT.

Calling the solver's simplifier after each parsed clause repairs the tiny
example but still returns invalid SAT models on larger CNFs generated by HOL4.
That patch is therefore not treated as a fix and is not part of any accepted
build.

The architecture-specific cause is now isolated.  AArch64 GCC defines
`__CHAR_UNSIGNED__`, while this MiniSat fork stores the lifted Boolean values
`-1`, `0`, and `1` in `vec<char> assigns`.  Reading stored false assignments
back as 255 corrupts the solver's three-valued comparisons.  Building the
exact committed source with `-fsigned-char`, without the experimental parser
change, made all 16 retained failing HOL-generated CNFs return exit 20 and
made the bundled resolution traversal end at the empty clause.

[`build_upstream_hol_minisat.py`](../tools/build_upstream_hol_minisat.py)
extracts source blobs from the pinned HOL4 commit rather than the possibly
dirty worktree, verifies that `-fsigned-char` clears `__CHAR_UNSIGNED__`, and
hash-binds the compiler, sources, build log, and output executable.
[`audit_upstream_hol_minisat.py`](../tools/audit_upstream_hol_minisat.py) then
checks the retained seven-variable regression CNF in two ways: MiniSat's own
resolution traversal must reach the empty clause, and `minisatProve.GEN_SAT`
must return a HOL4 kernel theorem without its internal-DPLL fallback warning.
The direct and HOL-invoked 95-byte proof traces are required to be identical.
